## 📱 Descripción

**Darknote** es una aplicación Android moderna para tomar notas con un diseño oscuro elegante y una interfaz intuitiva. Permite a los usuarios crear, editar, buscar y eliminar notas de manera eficiente, con persistencia local de datos.

## ✨ Características

- 🌑 **Tema oscuro nativo** - Diseño elegante y cómodo para la vista
- 📝 **Crear y editar notas** - Editor de texto completo
- 🔍 **Búsqueda en tiempo real** - Encuentra notas al instante
- 🗑️ **Eliminación con confirmación** - Diálogos de seguridad
- 💾 **Persistencia local** - Base de datos Room
- 🎨 **Material Design 3** - UI moderna y consistente
- 📱 **Responsive** - Adaptado a diferentes tamaños de pantalla

## 🛠️ Tecnologías

- **Kotlin** - Lenguaje principal
- **Jetpack Compose** - UI moderna
- **Room Database** - Persistencia local
- **Material 3** - Diseño visual
- **Coroutines** - Programación asíncrona
- **ViewModel** - Gestión de estado
- **Navigation Component** - Navegación entre pantallas

## 📦 Instalación

### Requisitos previos
- Android Studio Hedgehog o superior
- JDK 17+
- Android SDK 34
- Min SDK 24 (Android 7.0)
