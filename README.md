## 📱 Descripción
**Darknote** es una aplicación Android moderna para tomar notas con un diseño oscuro sofisticado y una interfaz intuitiva. Permite crear, editar, buscar y eliminar notas de manera eficiente, con persistencia local de datos.

## ✨ Características
- 🌑 **Tema oscuro nativo**: Diseño elegante y cómodo para la vista.
- 📝 **CRUD completo**: Crear, leer, actualizar y eliminar notas.
- 🔍 **Búsqueda en tiempo real**: Encuentra notas al instante.
- 💾 **Persistencia local**: Base de datos Room.
- 🎨 **Material Design 3**: UI moderna y consistente.
